Install SaloneUI in 2 Minutes

No terminal required, no build step, no dependencies. Copy the CDN tag or install through your favorite package manager.

Recommended

Step 1: The Fastest Way (CDN Link)

Zero build step • Instant load

Add this single line inside the <head> of your HTML file. That is it — all 37 SaloneUI components will work immediately:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/salone-ui@1.2.0/dist/salone-ui.min.css">

Prefer unminified for debugging? Use: https://cdn.jsdelivr.net/npm/salone-ui@1.2.0/dist/salone-ui.css

Starter Boilerplate

Step 2: Full HTML Starter Template

New to web development? Create an index.html file on your computer, paste this complete boilerplate, and double-click to view it in your browser:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My SaloneUI Website</title> <!-- SaloneUI Lightweight Stylesheet (<25KB) --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/salone-ui@1.2.0/dist/salone-ui.min.css"> </head> <body> <!-- Responsive Navigation Bar --> <nav class="navbar"> <a href="#" class="nav-brand"><strong>MyProject</strong></a> <div class="row gap-xs"> <a href="#about" class="button small outline">About</a> <a href="#contact" class="button small green">Contact</a> </div> </nav> <!-- Main Page Container --> <main class="container" style="padding: 3rem 1.5rem;"> <div class="card elevated center column" style="max-width: 580px; margin: 0 auto; text-align: center;"> <span class="badge green">Welcome to SaloneUI</span> <h1 style="margin-top: 0.5rem;">Build With Plain English</h1> <p style="color: var(--salone-text-muted);"> You are now building with ultra-lightweight, zero-config plain English CSS classes. </p> <div class="row gap-sm" style="margin-top: 1rem; justify-content: center;"> <button class="button green">Get Started</button> <button class="button outline">Learn More</button> </div> </div> </main> </body> </html>
Package Managers

Step 3: Setup via Package Manager

Working with a modern JavaScript toolchain, React, Next.js, Vite, or Vue? SaloneUI works seamlessly with all package managers:

Install using NPM in your terminal:

npm install salone-ui

Then import the stylesheet at your app root: import 'salone-ui/dist/salone-ui.min.css';

Fast, disk-efficient install with PNPM:

pnpm add salone-ui

Install with Yarn classic or modern:

yarn add salone-ui

Lightning-fast install with Bun:

bun add salone-ui

Add with Deno modern package manager:

deno add npm:salone-ui

In Next.js (App Router), install and import into app/layout.tsx:

// 1. Terminal: npm install salone-ui // 2. In app/layout.tsx: import 'salone-ui/dist/salone-ui.min.css'; export default function RootLayout({ children }: { children: React.ReactNode }) { return ( <html lang="en"> <body>{children}</body> </html> ); }

In Vite + React, import at the top of src/main.jsx or src/main.tsx:

// 1. Terminal: npm install salone-ui // 2. In src/main.jsx: import React from 'react'; import ReactDOM from 'react-dom/client'; import 'salone-ui/dist/salone-ui.min.css'; import App from './App'; ReactDOM.createRoot(document.getElementById('root')).render(<App />);

In Vue (src/main.js) or Svelte (src/main.js):

// Terminal: npm install salone-ui // In src/main.js: import { createApp } from 'vue'; import 'salone-ui/dist/salone-ui.min.css'; import App from './App.vue'; createApp(App).mount('#app');

In Laravel Blade templates (resources/views/layouts/app.blade.php):

<!-- Inside resources/views/layouts/app.blade.php --> <head> <meta charset="utf-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>{{ config('app.name') }}</title> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/salone-ui@1.2.0/dist/salone-ui.min.css"> </head>

Support

Troubleshooting for Beginners

Got a question or ran into a snag? Here are the most common solutions:

Why are my styles not appearing on the page?

Make sure your <link> tag is placed inside the <head> element, not inside <body>. Also verify that you have an active internet connection when using the CDN, or that the local relative path to salone-ui.css is correct.

Why doesn't my button look styled?

In SaloneUI, always include the base class button first! Modifiers like green or outline apply styling on top of the base: <button class="button green">. Writing only class="green" will not apply button padding or typography.

Why does mobile view look zoomed out on my phone?

Ensure you have included the standard viewport meta tag inside your <head>: <meta name="viewport" content="width=device-width, initial-scale=1.0">. Without this tag, mobile browsers will render the page at desktop width.

How do I turn on Dark Mode?

Simply add class="dark" to your <body> element: <body class="dark">. All cards, surfaces, text, inputs, and borders will immediately adapt with zero JavaScript configuration required.

Can I use SaloneUI together with other libraries?

Yes! SaloneUI does not perform aggressive CSS resets that collide with your existing styles. You can progressively introduce SaloneUI components into existing WordPress, React, Laravel, or custom projects.
