# Changelog

All notable changes to SaloneUI will be documented in this file.

---

## [1.2.0] - 2026-11-21

### Added
- **Component 37: Notice (Native Dialog)**: HTML5 `<dialog class="notice">` with 4 variants (success, error, warning, info), backdrop blur, and accessible focus management.
- **Multi-page Architecture**: Split documentation into dedicated URLs (`/docs`, `/installation`, `/components`, `/icons`) with clean routing.
- **Unified Navigation & Footer**: Global header and footer across all pages with mobile drawer.
- **Universal Icons Explorer**: Integrated catalog of 200,000+ vector SVG icons with instant search and zero broken images.
- **Sitemap & SEO**: Clean URLs indexed via `sitemap.xml` and rich Schema.org JSON-LD.

### Changed
- Aligned documentation, playground prompts, and CDN references to version 1.2.0.

---

## [1.1.0] - 2026-11-19

### Added
- Multi-theme switching support: Default Emerald, Fintech, Shop, School, and Dark Mode via 1-word classes on `<body>`.
- Command palette (`⌘K`) for fast keyboard navigation across components and documentation.
- Built-in Fintech components: `.money-card`, `.transaction` list items, and 4-digit `.pin-box` verification.

### Changed
- Optimized CSS bundle size to under 25KB minified.

---

## [1.0.0] - 2026-11-15

### Added
- Initial release of SaloneUI: the plain-English, zero-config CSS framework.
- 30+ responsive, accessible components with intuitive naming conventions (`button green`, `card elevated`, `grid 3`).
- Open source release under MIT License.
