2. Pure-CSS FAQ Accordion

Expandable FAQ with zero JavaScript using native <details class="accordion">.
What makes SaloneUI different from other CSS frameworks?
SaloneUI uses plain English class names with zero cryptic abbreviations (like button green, card, and grid 3). It works immediately with zero build step and stays strictly under 25KB minified.
Do I need Node.js or a build tool to use it?
No! You can drop 1 single CDN link into any HTML page and start styling immediately. If you do use Node.js, Next.js, or Vite, you can also install via npm install salone-ui.
Can I use SaloneUI with React, Next.js, Vue, or Svelte?
Yes, SaloneUI works seamlessly with modern web frameworks. Simply add import 'salone-ui/dist/salone-ui.min.css'; to your root file (like app/layout.tsx or src/main.js).
How do the 1-word themes work?
Just add class="theme-fintech", class="theme-shop", class="theme-school", or class="dark" to your <body> tag. The entire UI color palette transforms instantly with pure CSS.
Is SaloneUI completely free for commercial projects?
Yes! SaloneUI is released under the permissive MIT License. You can freely use it for commercial projects, client websites, open-source software, and mobile applications.
