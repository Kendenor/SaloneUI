The Cheat Sheet

You don't need to memorize long class names. Say the word you want and add the color or size you like. This page lists every word SaloneUI understands.

Layout & Helpers

container

Centers content to a 1140px width.

grid

A CSS grid. Add 2, 3 or 4 for columns on desktop.

row

A wrapping flex row.

column

A flex column with gap.

center

Everything centered.

space-between

Flex row, items pushed to the edges.

gap-sm / gap-md / gap-lg

Control the space between items.

hide-mobile / show-mobile

Toggle visibility on small screens.

Themes (one word on <body>)

Green / emerald palette.

theme-shop

Warm orange palette.

theme-school

Blue palette.

dark

Dark mode. Drop it on <body> or <html>.
