Starter Template (HTML)

Copy this ready-to-run template into an index.html file on your computer. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My New SaloneUI Project</title>
  <!-- CDN Link (or use local ./salone-ui.min.css) -->
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/salone-ui@1.0.0/dist/salone-ui.css">
</head>
<body>
  <!-- Navigation -->
  <nav class="navbar">
    <a href="#" class="nav-brand">My App</a>
    <button class="button small green">Get Started</button>
  </nav>

  <!-- Content Container -->
  <main class="container" style="padding: 3rem 1.5rem;">
    <div class="center column">
      <h1>Built with Plain English</h1>
      <p>Edit this file to start creating something amazing!</p>
      <button class="button big green">Click Me</button>
    </div>
  </main>
</body>
</html>
Works 100% Offline: SaloneUI does not require external font downloads or third-party web services. Once downloaded, you can build entire sites while disconnected from the internet.
