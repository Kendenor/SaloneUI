Instant Setup

Install in 10 Seconds

Use any package manager you like — NPM, PNPM, Yarn, Bun, Deno — SaloneUI works seamlessly with all of them. Or drop 1 CDN link into your HTML with zero install at all.

Add this line inside your <head> tag. No build step or terminal required:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/salone-ui@1.1.0/dist/salone-ui.css">

Minified CDN link: https://cdn.jsdelivr.net/npm/salone-ui@1.1.0/dist/salone-ui.min.css

Install using NPM into your modern web project:

npm install salone-ui

Fast, disk-efficient install with PNPM:

pnpm add salone-ui

Install with Yarn classic or modern:

yarn add salone-ui

Lightning-fast install with Bun:

bun add salone-ui

Add with Deno modern package manager:

deno add npm:salone-ui

In your Next.js project (App Router), install and import directly into app/layout.tsx:

// 1. Terminal: npm install salone-ui // 2. In app/layout.tsx: import 'salone-ui/dist/salone-ui.min.css'; export default function RootLayout({ children }: { children: React.ReactNode }) { return ( <html lang="en"> <body>{children}</body> </html> ); }

In Vite + React, install and import at the top of src/main.jsx or src/main.tsx:

// 1. Terminal: npm install salone-ui // 2. In src/main.jsx or src/main.tsx: import React from 'react'; import ReactDOM from 'react-dom/client'; import 'salone-ui/dist/salone-ui.min.css'; import App from './App'; ReactDOM.createRoot(document.getElementById('root')).render(<App />);

In Vue (src/main.js) or Svelte (src/main.js):

// Terminal: npm install salone-ui // Vue 3 (src/main.js): import { createApp } from 'vue'; import 'salone-ui/dist/salone-ui.min.css'; import App from './App.vue'; createApp(App).mount('#app'); // Or Svelte (src/main.js): import 'salone-ui/dist/salone-ui.min.css';

In Laravel Blade templates (resources/views/layouts/app.blade.php):

<!-- Inside resources/views/layouts/app.blade.php --> <head> <meta charset="utf-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>{{ config('app.name') }}</title> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/salone-ui@1.1.0/dist/salone-ui.min.css"> </head>

Core Highlights

7 Powerful Framework Features

Engineered for real-world projects, modern financial interfaces, and effortless developer happiness.

1

Magic 1-Word Themes

Switch your whole application by simply typing class="theme-fintech", class="theme-shop", or class="theme-school" on <body>.

2

Smart Components

One clean class does everything. No need for nested utility chains just to style a button or balance widget.

3

Auto-Layout Grids

class="grid 2" and class="grid 3" automatically collapse cleanly to 1 column on mobile phones and expand on laptops.

4

Built-in Fintech Ready

Native money-card, transaction lists, and 4-digit mobile money pin-box right out of the box.

5

Instant 1-Word Dark Mode

Just add class="dark" to <body>. Zero JavaScript needed, no CSS compiler plugins, no configuration file.

6

Copy-to-Use Everywhere

Every component in our documentation has a 1-click copy button. Copy the snippet, paste into your HTML, and you are done.
