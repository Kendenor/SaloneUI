# Contributing to SaloneUI

Welcome! We are excited that you want to help make SaloneUI better. 

You don't need to be an expert to help. Whether you are fixing a typo, designing a new component, or improving examples, every single contribution matters!

## How to Contribute in 3 Simple Steps

1. **Fork the Repository**
   - Click the "Fork" button at the top right of the GitHub page.
   - Clone your fork to your computer:
     ```bash
     git clone https://github.com/YOUR-USERNAME/SaloneUI.git
     ```

2. **Make Your Changes or Add a Component**
   - SaloneUI uses plain English class names (like `button green`, `card`, `transaction`).
   - If you are adding or refining a component, edit `src/salone-ui.css`.
   - Keep styling lightweight, modern, and accessible.

3. **Open a Pull Request**
   - Push your changes to your fork:
     ```bash
     git add .
     git commit -m "Add new component: badge glowing"
     git push origin main
     ```
   - Go to GitHub and click **New Pull Request**.
   - Describe what you added or changed in simple words.

## Guidelines
- **Plain English Only**: Do not use cryptic abbreviations like `btn`, `d-flex`, or `px-4`.
- **Zero Heavy JavaScript**: Components should look great with pure CSS.
- **Friendly Community**: Be kind, respectful, and supportive to everyone.

Thank you for building SaloneUI with us!
