Overview

1. What is SaloneUI?

SaloneUI is an open-source CSS framework engineered around one radical principle: your code should read like plain English.

Modern web styling has become plagued by endless utility chains — classes like bg-emerald-500 hover:bg-emerald-600 text-white font-medium py-2 px-4 rounded-lg shadow-sm transition-all duration-200. While powerful, they turn your HTML into an unreadable soup, demand extensive cheat sheet lookups, and require Node.js build pipelines just to see a styled button.

In SaloneUI, that same button is simply:

<!-- SaloneUI: Clean, readable, and human-first --> <button class="button green">Confirm Transfer</button>

< 25 KB

Minified & lightning fast on any 3G/4G network.

0 Config

No Node.js, Webpack, PostCSS, or config files required.

37+ Components

Buttons, cards, dialogs, auto-grids, and fintech widgets.

Philosophy

2. Why Use SaloneUI?

SaloneUI was crafted to solve the real frustrations developers, beginners, and teams face every day:

Natural English Syntax

Classes are intuitive plain English words: card elevated, button green small, grid 3, alert success. Junior developers, designers, and experienced engineers instantly understand the markup without reading documentation.

Zero Build Step

No waiting for compilers, no 500MB node_modules folder, and no broken bundler configs. Link the stylesheet from CDN or local file, open your browser, and build immediately.

Fintech & Real-World Ready

Engineered with built-in financial primitives: .money-card balance displays, transaction ledger items, and 4-digit mobile money .pin-box widgets tailored for modern apps.

AI Coding Assistant Friendly

Because SaloneUI uses natural language, AI models like Claude, ChatGPT, and Gemini write flawless SaloneUI code on the first try without guessing cryptic utility names.

Architecture

3. How It Works

SaloneUI follows three straightforward syntax rules that apply across all 37 components:

Rule 1: Component Name First

Every element begins with its base component noun: button, card, input, badge, alert, grid, notice.

Rule 2: Plain Adjectives for Modifiers

Add natural adjectives to change colors, sizes, or borders. Combine them in any order:

  • Colors: green, blue, orange, red, black, white
  • Styles: outline, elevated, pill, striped
  • Sizes: small, big

Rule 3: Auto-Responsive Grid

Layouts are set with class="grid 2", class="grid 3", or class="grid 4". They automatically collapse to a single clean column on mobile phones without needing media query utility prefixes.

1-Word Theming & Dark Mode

Theme your entire application instantly by adding a single class to the <body> tag:

<!-- Instant Dark Mode --> <body class="dark"> <!-- Or 1-Word Themes --> <body class="theme-fintech"> <body class="theme-shop"> <body class="theme-school">

4. Quick Example

Here is what real SaloneUI code looks like in action. A modern card with status badge, responsive grid metrics, and action buttons:

Active Account ID: #SL-2409

Aminata Kamara

Freetown, Sierra Leone • Business Tier

Balance SLE 45,200
Points 1,420 pts 
<div class="card elevated">
  <div class="row space-between">
    <span class="badge green">Active Account</span>
    <span class="text-muted">ID: #SL-2409</span>
  </div>

  <h3>Aminata Kamara</h3>
  <p>Freetown, Sierra Leone • Business Tier</p>

  <div class="grid 2">
    <div class="card">
      <span>Balance</span>
      <strong class="text-green">SLE 45,200</strong>
    </div>
    <div class="card">
      <span>Points</span>
      <strong class="text-blue">1,420 pts</strong>
    </div>
  </div>

  <div class="row gap-xs">
    <button class="button green small">Send Money</button>
    <button class="button outline small">Statement</button>
  </div>
</div>
